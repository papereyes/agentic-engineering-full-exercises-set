# Evidence Policy

- Cite a verification result only when supplied evidence marks it passed.
- Include the evidence ID beside each claimed pass.
- Preserve supplied check names verbatim so each claim remains auditable.
- Report missing evidence explicitly; never convert it into a pass.
- Keep evidence attached to the customer change it verifies.
- Do not infer test execution from changed test files or a PR description.
- Distinguish verified behavior from incomplete visual or operational proof.
- Omit evidence for unrelated internal changes.
