# Publication Policy

- Use the exact requested Git range.
- Publish only behavior a customer can observe.
- Give each customer change a `###` heading.
- Add a `- Trace:` line with a changed path or commit from the range.
- PR descriptions may explain a change but cannot replace its Git trace.
- Exclude internal telemetry, refactors, tests, and build-only work.
- If nothing qualifies, state that no customer-facing changes were found.
- Support an exclusion decision with the range and inspected Git evidence.
