Root cause: run-clean-verification.mjs snapshots ignored files via
`execFileSync("git", ["ls-files", "--others", "--ignored", "--exclude-standard", "-z"])`
before filtering node_modules out in JS. This is a repo-wide git invocation
(not scoped to this exercise), so it reflects every installed node_modules
tree across the checkout. Linux's default pipe buffer
(/proc/sys/fs/pipe-max-size = 1048576 bytes) cannot hold that output, so the
synchronous git subprocess fails with ENOBUFS. Confirmed independent of
Node version (system Node v25.9.0 and Node v22.12.0 matching .nvmrc both
fail identically), independent of sandbox flags, and not reproducible via a
plain shell pipe (`git ls-files ... | wc -c` succeeds) -- isolating it to
execFileSync's interaction with the kernel pipe cap. Raising
fs.pipe-max-size requires root; no passwordless sudo is available in this
environment, so it was not attempted.
