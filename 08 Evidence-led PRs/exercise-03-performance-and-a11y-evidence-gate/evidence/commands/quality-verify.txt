Root cause: run-clean-verification.mjs snapshots ignored files via
`execFileSync("git", ["ls-files", "--others", "--ignored", "--exclude-standard", "-z"])`
before filtering node_modules out in JS. quality-gate-app's installed
dependency tree (Lighthouse + Playwright + axe-core, 15k+ files) produces
more than 1MB of ignored-path output, and Linux's default pipe buffer
(/proc/sys/fs/pipe-max-size = 1048576 bytes) cannot hold it, so the
synchronous git subprocess fails with ENOBUFS. Confirmed independent of
Node version (reproduced on both system Node v25.9.0 and Node v22.12.0
matching .nvmrc), independent of sandbox flags, and not reproducible via a
plain shell pipe (`git ls-files ... | wc -c` succeeds with 2.26MB of
output) -- isolating it to execFileSync's interaction with the kernel pipe
cap. Raising fs.pipe-max-size requires root; no passwordless sudo is
available in this environment, so it was not attempted.
